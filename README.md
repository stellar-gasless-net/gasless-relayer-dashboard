# `gasless-relayer-dashboard`

Developer Portal & Admin Console for managing Paymaster gas deposits, API Keys, and monitoring live meta-transaction relays on **Stellar Gasless Network**.

## 🎨 UI Features

- **Live Analytics**: Real-time tracking of total relayed transactions, sponsored gas budget, and relayer latency.
- **Paymaster Deposit Manager**: Interface for dApp developers to top up XLM and SAC token gas pools.
- **API Key Management**: Generate and scope keys for frontends consuming `@stellar-gasless/sdk`.

## 🚀 Running

```bash
npm start
```
